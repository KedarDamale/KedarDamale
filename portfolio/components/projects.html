Chessablanka

A camera-ready route from a board photograph to an engine-analyzed chess position.

  • Analyzing a chess position from a photo usually means transcribing the board by hand before an engine can evaluate it—a slow, error-prone step.
  • Built an end-to-end computer-vision pipeline to detect the board and map its grid. The custom YOLOv8 model was trained on more than 700 images and expanded to 1,700 through augmentation with Roboflow.
  • Reached 98.57% detection accuracy across more than 500 test images, then connected recognized positions to Stockfish for immediate evaluation and best-move analysis.

NeuroTRIBE

Reproducible cortical-response analysis for an ADHD research question.

  • Studying whether ADHD is associated with differences in stimulus-evoked cortical responses calls for a repeatable comparison with a matched group.
  • Built a TRIBE v2 analysis pipeline using Healthy Brain Network movie-fMRI data to compare participants with confirmed ADHD against a matched cohort.
  • Added Docker Compose orchestration for repeatable cohort-level exploration. Restricted input data stays outside the workflow, so access requirements do not block setup.

Cattle Monitoring

A field-to-dashboard system for understanding free-grazing cattle movement.

  • Farmers monitoring free-grazing cattle relied on manual rounds, making it difficult to track herd locations and recurring grazing patterns.
  • Led a team that built a distributed tracking system. One ESP32 master and multiple child nodes send GPS and RSSI readings to a Flask and MongoDB backend.
  • Used DBSCAN to identify grazing zones and displayed them on a live Next.js dashboard, giving farmers a clearer view of herd movement.
