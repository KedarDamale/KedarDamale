Chessablanka

A camera-ready route from a board photograph to an engine-analyzed chess position.

  • Analysing a chess position from a photograph traditionally requires manually transcribing the board before an engine can evaluate it, making the process slow and error-prone.
  • Built an end-to-end computer-vision pipeline that detects the board and maps its grid using a custom YOLOv8 model trained on 700+ images and augmented to 1,700 with Roboflow.
  • Achieved 98.57% detection accuracy across 500+ test images and connected recognized positions to Stockfish for immediate evaluation and best-move analysis.

NeuroTRIBE

Reproducible cortical-response analysis for an ADHD research question.

  • Testing whether ADHD is associated with differences in stimulus-evoked cortical responses requires a reproducible comparison against an appropriately matched baseline.
  • Built a TRIBE v2 analysis pipeline over Healthy Brain Network movie-fMRI data to compare participants with confirmed ADHD against a matched cohort.
  • Added Docker Compose orchestration to make cohort-level exploratory analysis repeatable while keeping legally gated inputs outside the workflow and non-blocking.

CASE 03 IOT + GEOSPATIAL ML

03 / 03  ·  IOT + GEOSPATIAL ML

2025

Cattle Monitoring

A field-to-dashboard system for understanding free-grazing cattle movement.

  • Farmers monitoring free-grazing cattle had to rely on manual rounds, making it hard to see herd locations and recurring grazing patterns in real time.
  • Led a team building a distributed tracking system with one ESP32 master and multiple child nodes that send GPS and RSSI readings to a Flask and MongoDB backend.
  • Applied DBSCAN to identify grazing zones and displayed the resulting locations on a live Next.js dashboard, giving farmers a clearer view of herd movement.
