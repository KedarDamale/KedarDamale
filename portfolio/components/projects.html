03. Some Things I’ve Built

  • Featured Project

    Chessablanka

    An end-to-end computer-vision pipeline that reads a physical chessboard from a photo, reconstructs its position, and connects it to Stockfish. Achieved 98.57% detection accuracy across 500+ test images.

    • YOLOv8
    • Roboflow
    • OpenCV
    • Stockfish

  • Featured Project

    NeuroTRIBE

    A reproducible research pipeline for comparing stimulus-evoked cortical responses in participants with ADHD and a matched cohort. Built around TRIBE v2, Healthy Brain Network movie-fMRI data, and containerized cohort analysis.

    • Python
    • fMRI
    • TRIBE v2
    • Docker

  • Featured Project

    Cattle Monitoring

    A distributed herd-monitoring system combining GPS and RSSI telemetry from ESP32 devices. DBSCAN identifies grazing zones, with movement and spatial patterns displayed on a live dashboard.

    • ESP32
    • DBSCAN
    • Flask
    • MongoDB
    • Next.js
