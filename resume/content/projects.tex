\entryline{1. Chessablanka -- Chess Position Analyzer $|$ \myhref{https://github.com/KedarDamale/Chessablanka}{GitHub}}{Apr 2025 -- Jan 2026}
\begin{itemize}
  \item Converting a chessboard photo into a position an engine can analyze usually requires manual transcription, making the process slow and error-prone.
  \item Built an end-to-end computer-vision pipeline with OpenCV to detect the board and map its grid. Trained a custom YOLOv8 model on a Roboflow-augmented dataset expanded from 700+ to 1,700 images.
  \item Achieved 98.57\% detection accuracy on 500+ test images and integrated Stockfish for immediate position evaluation and best-move analysis.
\end{itemize}

\entryline{2. NeuroTRIBE -- Cortical Response Analysis for ADHD Research $|$ \myhref{https://github.com/KedarDamale/NeuroTribe}{GitHub}}{Aug 2026 -- Present}
\begin{itemize}
  \item A reproducible analysis was needed to test whether ADHD is associated with differences in stimulus-evoked cortical responses.
  \item Built a TRIBE v2 analysis pipeline using Healthy Brain Network movie-fMRI data to compare participants with confirmed ADHD against a matched cohort.
  \item Added Docker Compose orchestration for repeatable cohort-level exploration and kept legally restricted inputs outside the workflow so their access requirements do not block setup.
\end{itemize}

\entryline{3. Cattle Monitoring Using DBSCAN and ESP32 $|$ \myhref{https://github.com/KedarDamale/ESP32-DBSCAN-Cattle-Monitoring-System}{GitHub}}{Oct 2025 -- Nov 2025}
\begin{itemize}
  \item Farmers monitoring free-grazing cattle relied on manual rounds, making it difficult to track herd locations and recurring grazing patterns.
  \item Led a team that built a distributed tracking system: one ESP32 master and multiple child nodes sent GPS and RSSI readings to a Flask and MongoDB backend.
  \item Applied DBSCAN to identify grazing zones and mapped them on a live Next.js dashboard, giving farmers a clearer view of herd movement.
\end{itemize}
