\entryline{1. Chessablanka -- Chess Position Analyzer $|$ \myhref{https://github.com/KedarDamale/Chessablanka}{GitHub}}{Apr 2025 -- Jan 2026}
\begin{itemize}
  \item Analysing a chess position from a photograph normally requires expert board transcription and evaluation.
  \item Built an end-to-end CV pipeline for board detection and grid mapping with a custom YOLOv8 model trained on 700+ images, augmented to 1,700 via Roboflow.
  \item Achieved 98.57\% detection accuracy on 500+ test images and sent positions to Stockfish for instant evaluation and best-move analysis.
\end{itemize}

\entryline{2. NeuroTRIBE -- Cortical Response Analysis for ADHD Research $|$ \myhref{https://github.com/KedarDamale/NeuroTribe}{GitHub}}{Aug 2026 -- Present}
\begin{itemize}
  \item No existing tool objectively tests whether ADHD alters stimulus-evoked cortical responses against a baseline.
  \item Built a TRIBE v2 pipeline over Healthy Brain Network movie-fMRI data to compare confirmed-ADHD participants with a matched cohort.
  \item Enabled autonomous Docker-Compose orchestration for objective analysis while treating legally gated inputs as non-blocking.
\end{itemize}

\entryline{3. Cattle Monitoring using DBSCAN and ESP32 $|$ \myhref{https://github.com/KedarDamale/ESP32-DBSCAN-Cattle-Monitoring-System}{GitHub}}{Oct 2025 -- Nov 2025}
\begin{itemize}
  \item Farmers lacked a way to track free-grazing cattle without performing manual rounds.
  \item Led a team building a distributed system of one ESP32 master and N child nodes, streaming GPS/RSSI data to a Flask/MongoDB backend.
  \item Applied DBSCAN to automatically identify grazing zones on a live Next.js tracking dashboard.
\end{itemize}
