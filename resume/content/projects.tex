\sectiontitle{PROJECTS}

\entryline{Chessablanka -- Chess Position Analyzer $|$ \href{https://github.com/KedarDamale/Chessablanka}{GitHub}}{Apr 2025 -- Jan 2026}
\begin{itemize}
  \item Evaluating a chess position from a photo normally needs an expert, so built an end-to-end CV pipeline with board detection, grid mapping, and a custom YOLOv8 model trained on 700+ images (augmented to 1,700 via Roboflow).
  \item Achieved 98.57\% detection accuracy on 500+ test images and piped positions into Stockfish for instant real-time evaluation and best-move analysis.
\end{itemize}

\entryline{StudyONE -- Student Productivity \& Collaboration Platform $|$ \href{https://github.com/KedarDamale/StudyONE}{GitHub}}{Aug 2024 -- Oct 2024}
\begin{itemize}
  \item Students relied on scattered tools for notes and collaboration, so built a full-stack MERN platform with JWT auth, a personalized dashboard, and a real-time collaborative whiteboard.
  \item Manually converting lectures into notes was slow, so integrated Rev.ai and Google Cloud Speech-to-Text into an AI notes pipeline and deployed the app to production on Render.
\end{itemize}

\entryline{Cattle Monitoring using DBSCAN and ESP32 $|$ \href{https://github.com/KedarDamale/ESP32-DBSCAN-Cattle-Monitoring-System}{GitHub}}{Oct 2025 -- Nov 2025}
\begin{itemize}
  \item Farmers had no way to track free-grazing cattle without manual rounds, so led a team to build a distributed IoT system (1 ESP32 master + N child nodes) streaming GPS/RSSI data to a Flask/MongoDB backend, applying DBSCAN clustering to auto-identify grazing zones on a Next.js live-tracking dashboard.
\end{itemize}

\entryline{NeuroTRIBE-HBN -- Cortical Response Analysis for ADHD Research $|$ \href{https://github.com/KedarDamale/NeuroTribe}{GitHub}}{Aug 2026 -- Present}
\begin{itemize}
  \item No existing tool tests whether ADHD alters stimulus-evoked cortical response against an objective baseline, so built a research pipeline applying TRIBE v2 to Healthy Brain Network movie-fMRI data, comparing confirmed-ADHD participants against a matched cohort via an autonomous, Docker-Compose orchestration layer that treats legally-gated inputs as non-blocking.
\end{itemize}
